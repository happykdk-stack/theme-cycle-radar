# 한미 주식 테마 사이클 레이더

한국·미국 대표 테마 ETF의 일별 종가와 거래량을 수집하여 GitHub Pages에서 자동으로 표시하는 프로젝트입니다. CSV 업로드가 필요 없습니다.

## 1. 설치 (GitHub 웹사이트만 사용)

1. GitHub에서 **New repository**를 눌러 `theme-cycle-radar`라는 **Public** 저장소를 만들고, 기본 브랜치를 `main`으로 설정합니다. (Private 저장소의 Pages 사용 가능 여부는 요금제에 따라 다릅니다.)
2. 이 ZIP을 풀고 **숨김 폴더 `.github`를 포함한 모든 파일과 폴더**를 저장소 루트에 업로드합니다. `site/index.html`, `scripts/update_v4.py`, `.github/workflows/main.yml`, `requirements.txt`가 있어야 합니다.
3. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 변경합니다.
4. 저장소 **Actions → Refresh theme radar and deploy → Run workflow**를 실행합니다.
5. 작업이 성공하면 `https://<사용자명>.github.io/theme-cycle-radar/`에서 확인합니다. 첫 배포까지 몇 분 걸릴 수 있습니다.
6. Actions 탭의 작업 로그에서 `Saved N themes; M errors` 메시지를 확인합니다. 일부 ETF가 실패하면 사이트의 **데이터 수집 오류 및 한계**에도 표시됩니다.

> GitHub Actions의 예약 실행은 지연되거나 생략될 수 있으며, 무료 금융 데이터 제공처의 접속 제한이 발생할 수 있습니다. 매일 정시 업데이트를 보장하지 않습니다.

## 2. 갱신 방식

- `.github/workflows/main.yml`이 평일 **UTC 09:30, 22:30**에 실행됩니다. 한국시간 **18:30, 다음날 07:30**으로 한국·미국 장 마감 후 갱신합니다. 공급자 반영이 늦으면 해당 시간대 신호등은 회색으로 표시될 수 있습니다.
- **Run workflow**로 수동 갱신도 가능합니다.
- 브라우저의 **최신 데이터 다시 읽기** 버튼은 이미 배포된 JSON을 다시 불러옵니다. 서버 수집 작업 자체를 실행하지는 않습니다.
- 데이터가 36시간 이상 오래되면 화면에 경고가 표시됩니다. 주말에는 정상적으로 이 경고가 뜰 수 있습니다.

## 3. 분석 규칙과 해석

**신호:** ETF 종가 기준 전 거래일 대비 **3% 이상 상승**하고 **거래량이 전 거래일의 1.5배 이상**이면 발생합니다. ETF마다 신호를 독립적으로 계산합니다. 해당 일자의 종가가 확정된 뒤에야 신호를 알 수 있습니다.

**점수:** 거래량 강도 30%, 벤치마크 대비 20거래일 상대강도 25%, 가격방향 가중 거래량 대리지표 20%, 테마 확산 **중립값 50** 15%, 최근 10거래일 상승 빈도 10%.

- 한국 벤치마크: `069500.KS` (KODEX 200), 미국: `SPY`.
- 기관/외국인 순매수, 개별 구성종목 동반 상승 데이터는 **제공하지 않습니다**. 따라서 수급·확산을 실제 측정했다고 해석하면 안 됩니다.
- 신호 후 5·20거래일 수익률은 **신호일 종가 기준**이며, 다음날 시가 체결을 가정한 전략 수익률이 아닙니다. 거래비용, 배당 재투자, 세금 및 슬리피지는 제외합니다.
- 가격은 yfinance의 `auto_adjust=True`로 조정된 일별 시세입니다. 공급자 수정에 따라 과거 수치가 바뀔 수 있습니다.
- 종목별 상장 시기·ETF 추종 지수 차이·레버리지 여부가 비교에 영향을 줍니다. 테마 ETF가 테마 전체의 움직임을 완전히 대표하지는 않습니다.
- 점수 임계값(75/60/40)은 실험적이며 검증된 예측 정확도를 의미하지 않습니다.
- ETF 상장폐지나 티커 변경이 있으면 `scripts/update.py`의 `THEMES`를 수정하세요.

## 4. 로컬 테스트

Python 3.11 이상 환경에서:

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
node --test tests/test_dashboard.cjs
python scripts/update_v4.py
python scripts/validate_site.py
python -m http.server 8000 --directory site
```

브라우저에서 `http://localhost:8000`을 열어 확인합니다. 단순히 `site/index.html`을 파일로 직접 열면 일부 브라우저에서 JSON fetch가 차단될 수 있습니다.

## 5. 데이터 실패 시

- **전체 수집 실패:** workflow가 실패하며 신규 사이트 배포를 중단합니다. 기존 Pages 사이트가 있다면 마지막 성공 배포본이 남습니다. 화면의 생성 시각을 확인하세요.
- **일부 수집 실패:** 성공한 ETF만 표시하고 실패한 티커 및 원인을 오류 영역에 표시합니다.
- **실패 원인:** Yahoo Finance 접속 제한, 한국 ETF 심볼 변경, 휴장일, API 응답 오류 등. Actions 로그를 확인하고 재실행하세요.
- 데이터 공급자 이용 약관 및 호출 제한을 확인하고 개인 연구용으로 사용하세요.


**주의:** 이 프로젝트는 시장 관찰용 시제품입니다. 1년간 전체 테마에 대한 검증된 정확도 수치는 아직 제공하지 않습니다.

## 7. ETF 월·주·일 신호등 (Cycle Detector 4.2 유지)

화면 최상단에는 **증권 ETF 종합 신호등**을 고정된 첫 패널로 배치합니다. [삼성자산운용 공식 안내](https://www.samsungfund.com/upload/kodex/newsroom/20250722174437650.pdf)의 KODEX 증권(102970)을 사용하고, `102970.KS` 시세를 별도로 수집해 `securities_etf.etf_trend`에 기록합니다. 이 패널은 한국/미국 필터와 관계없이 유지되며 월·주·일 상태, 종합 신호, 최근 변경일과 기준일을 표시합니다. 수집 실패 시 회색으로 표시하고 오류를 기록합니다. 기존 14개 테마 및 시장 내 점수 순위에는 증권 ETF를 추가하지 않습니다.

`scripts/traffic_lights.py`는 기존 4.2 점수·단계·전환 강도·5일 변화·조건 확인도와 독립적으로 계산합니다. `data.json`의 각 ETF에 `etf_trend`를 추가하며 기존 필드와 계산식은 유지합니다.

- 한국 XKRX, 미국 XNYS 거래소 달력의 장 마감 시각(UTC), 휴장일 및 조기 폐장을 사용합니다. 일봉은 마감한 거래일만 사용합니다. 진행 중인 주·월봉은 최신 완료 거래일 종가로 판정하고, 주·월 마지막 예정 거래일이 마감하면 확정합니다. 금요일 휴장 시 목요일 종가가 주봉 종가가 될 수 있습니다.
- 각 시간대의 최신 종가(진행 중인 주·월봉 포함)가 MA5보다 높고 MA5가 직전 완성봉의 MA5보다 높으면 **상승**입니다. 두 부등호가 모두 반대면 **하락**, 나머지(같음 포함)는 **혼재·보합**입니다. MA5 방향을 비교하므로 최소 6개 완성봉이 필요합니다.
- **종합 초록**=3개 상승, **빨강**=3개 하락, **노랑**=혼재·보합, **회색**=한 시간대라도 데이터 부족입니다. 신호는 색상과 텍스트를 함께 표시합니다.
- 일봉 종가 누락·비정상 값은 일봉 MA5 계산에서 데이터 부족으로 처리합니다. 주·월봉은 해당 기간의 최종 예정 거래일 종가를 사용하며, 기간 중간의 일봉 누락만으로 유효한 주·월말 종가를 버리지 않습니다. 최종 종가 누락 또는 상장 첫 불완전 주·월은 완성봉으로 채우지 않습니다. 예정된 최신 마감봉이 누락되면 이전 상승 신호를 최신 신호로 대신 표시하지 않습니다. 수집 실패 ETF도 회색 행으로 남깁니다.
- `last_changed`는 각 과거 거래일 당시 완료된 일봉과 그날까지의 진행 중인 주·월봉만 사용해 종합 색상이 마지막으로 바뀐 거래일입니다. 최초 유효 신호는 `initial_since`에 기록하며 변경으로 세지 않습니다. 이력은 최근 60건을 제공합니다. 수집 범위(테마 18개월, 증권 ETF 5년) 이전의 변경일은 알 수 없고, 조정주가·공급자 수정·거래소 달력 수정에 따라 재계산 결과가 달라질 수 있습니다.
- 화면에서 시간대별 기준일, 종가, MA5, 직전 MA5를 확인할 수 있습니다. 한국/미국 필터는 ETF 표, 색상별 개수 및 기존 4.2 표에 함께 적용합니다.
- 배포 전 Python 계산·회귀 테스트와 Node 화면 테스트를 실행하고 생성 JSON을 검증합니다. `site/build.json`에 게시 커밋과 생성 시각을 남깁니다. 전체 수집 실패 또는 신호 계산 오류면 기존 게시본을 유지합니다.

이 신호는 ETF 추세를 설명하며 개별 종목 진입이나 매매를 자동 실행하지 않습니다.

## 8. 증권 ETF 최근 3년 모두 초록 이력

최상단 KODEX 증권 패널에서 가장 최근 월·주·일 동시 초록 날짜, 해당 연속 구간의 시작·종료일과 현재 유지 여부를 표시합니다. 전체 구간은 펼쳐서 확인합니다. `securities_etf.etf_trend.green_history`에 조회 범위, `latest_date`, `latest_run`, `runs`, `complete`를 기록합니다.

- 조회 범위는 최신 거래소 완료 거래일부터 달력상 3년 전 같은 날짜까지(양 끝 포함)입니다. 윤년은 pandas의 달력 연도 규칙을 사용합니다.
- 각 완료 거래일마다 당시 진행 중이던 월·주봉 종가와 이전 완료 기간의 종가로 MA5 및 직전 MA5를 계산합니다. 이후 주말·월말의 가격을 과거 날짜에 적용하지 않습니다. 현재 신호, 변경 이력 및 녹색 유지 수익률도 같은 일별 판정을 재사용합니다.
- 연속은 거래소 거래일 기준입니다. 주말·휴장일은 끊지 않으며 노랑·빨강·회색은 구간을 끊습니다. 단 하루의 초록도 구간입니다. 종료된 구간의 종료일은 마지막 초록 거래일이며, 유지 중인 구간은 최신 완료 거래일을 종료일로 표시합니다.
- 조회 범위와 겹치는 구간은 수집 데이터에서 관찰된 실제 시작일을 유지하므로 시작일이 3년 범위 이전일 수 있습니다. 시작 전 데이터가 없는 경우 더 이른 시작 여부를 알 수 없습니다.
- 증권 ETF만 같은 수집기로 5년을 조회해 월봉 최소 6개 기간의 준비 구간을 확보합니다. 테마 점수의 수집 범위는 유지합니다.
- 모든 조회 거래일의 판정이 유효하고 초록이 없으면 **최근 3년간 없음**으로 표시합니다. 수집 실패·짧은 이력·누락으로 판정이 부족하면 데이터 부족을 명시하고 확인 가능한 구간만 표시합니다. 공급자의 조정주가 및 달력 수정에 따라 과거 재계산 값이 달라질 수 있습니다.

## 9. 테마별 신호등 상승 점수

기존 새로운 사이클 조기 징후 TOP 3와 조기 징후 열·계산을 제거하고, 모든 테마 ETF의 신호등 상승 점수 표를 표시합니다. 시장 필터를 적용하며 점수 내림차순으로 정렬합니다. 각 ETF의 `etf_trend.bullish_score`에 점수를 기록합니다.

- 월봉 상승이면 50점, 주봉 상승이면 30점, 일봉 상승이면 20점을 합산합니다. 혼재·보합 또는 하락이면 해당 기간은 0점입니다. 예: 월·주 상승은 80점, 주·일 상승은 50점, 세 기간 모두 상승은 100점입니다.
- 최대 100점이며 추세의 일치도를 나타냅니다. 통계적으로 검증한 실제 상승 확률이나 매수 비중을 뜻하지 않습니다.
- 기존 거래소 완료 거래일 및 월·주·일 판정을 재사용합니다. 장중·미래 데이터는 사용하지 않으며 진행 중인 월·주봉은 최신 완료 거래일까지만 반영합니다.
- 한 기간이라도 데이터가 부족하거나 최신 시세가 누락되어 종합 신호가 회색이면 `null`로 기록하고 화면에 데이터 부족으로 표시합니다. 유효한 하락·혼재 상태의 0점과 구분합니다.
- 증권 ETF의 최근 3년 초록 유지 구간과 기존 사이클 강도·단계 표는 계속 제공합니다.

## 10. 신호등 중심 화면

사이클 위치·강도·전환 이력 영역을 화면에서 제거하고 테마 표의 첫 열에 종합 신호등을 표시합니다. 기존 데이터 형식의 사이클 필드는 호환성을 위해 유지하지만 화면에 사용하지 않습니다. 점수의 판정 근거를 펼치면 각 시간대의 종가·MA5·직전 MA5와 기준일을 볼 수 있습니다. 0점은 월·주·일 중 상승 조건(종가 > MA5, MA5 > 직전 MA5)을 만족하는 기간이 없음을 뜻하며 상승 가능성 0%를 뜻하지 않습니다.
