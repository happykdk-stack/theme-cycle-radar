# KRX 종합지수 PER 자료 연결

KRX Data Marketplace의 **지수 → 주가지수 → PER/PBR/배당수익률**에서 합법적으로 확보한 데이터만 사용하세요.

현재 KRX PER을 인증 없이 자동 수집하는 경로는 검증되지 않았습니다. 제공처의 라이선스·재배포 조건을 확인한 뒤, 허가된 자료만 저장소의 `data/krx_index_per.csv`에 아래 열로 입력할 수 있습니다.

```csv
date,ticker,pe,source
```

- `date`: YYYY-MM-DD
- `ticker`: ^KS11(코스피), ^KQ11(코스닥), ^KS200(코스피200)
- `pe`: 실제 PER 배수
- `source`: KRX 출처와 권한이 확인된 자료 설명

이 파일은 샘플 수치 없이 헤더만 제공됩니다. 원자료의 이용 조건이 GitHub Pages 공개 배포를 허용하지 않는다면 공개 저장소에 업로드하지 마세요. 그 경우 비공개 분석용으로만 사용해야 합니다.

실제 관측값이 없으면 차트에는 N/A가 표시됩니다. 지수 가격만으로 PER을 역산하지 않습니다.
